# Contributing to Coagmentator

Coagmentator is being developed in public with security and auditability treated as first-class requirements.

Before contributing, read:

- `AGENTS.md`
- `docs/PROJECT.md`
- `docs/ARCHITECTURE.md`
- `docs/SECURITY.md`
- `docs/ROADMAP.md`

Keep pull requests narrowly scoped to a roadmap gate. Include tests and verification evidence for implementation changes.

Every substantive contribution should also preserve handoff context according to `docs/WORK-CHAT-PROTOCOL.md`.

Do not submit secrets, production credentials, private keys or live authentication tokens.
