# Work Notes

This directory contains durable handoff notes between work sessions.

Each substantive work session must leave one.

## Template

```markdown
# Work Note: <topic>

Date: YYYY-MM-DD
Roadmap gate: Gate N
Status: COMPLETE | PARTIAL | BLOCKED

## Goal

<What this session was supposed to accomplish.>

## Starting state

- Branch:
- Starting commit:
- Relevant PR:
- Relevant deployment/version:

## Work completed

- ...

## Files changed

- `path/to/file`

## Verification

- test command and result
- manual verification and result
- CI run and result

## Decisions

- durable decision or "None"

## Risks / unresolved items

- ...

## Exact next step

<One clear next action for the next work session.>

## References

- commit:
- PR:
- workflow run:
- release/tag:
```

Do not include credentials, tokens, passwords, private keys or hidden reasoning.
